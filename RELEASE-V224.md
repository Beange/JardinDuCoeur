# Release V224 — Continuité du journal

Version applicative : **1.6.7 · build 224**.

## Changements

- Le contexte de date est désormais visible dans la seconde partie de « Ma journée ».
- Ajout d’un raccourci « Aujourd’hui » dans la navigation quotidienne.
- La navigation vers une journée future est bloquée pour éviter les saisies accidentelles.
- Le bouton « jour suivant » est désactivé lorsque la journée sélectionnée est aujourd’hui.
- Ajout d’un accès direct au Journal depuis la seconde partie de la journée.
- Suppression des icônes « + » décoratives qui pouvaient être prises pour des actions.

## Périmètre

Le corpus religieux reste en standby. Aucun fichier du dossier `data/` n’est modifié par cette release.
