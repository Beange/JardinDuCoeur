# Release V219 — Continuité journal & objectifs

- Version : **1.6.2 · build 219**
- Corpus religieux : **standby, inchangé**.
- Les objectifs disposent maintenant d’un état en cours/terminé et d’une date de réalisation.
- Les anciens objectifs sont migrés sans perte ; un objectif déjà coché reçoit une date de fin lors de la migration.
- Le panneau Objectifs distingue les éléments en cours de l’historique terminé et permet de réactiver un objectif.
- Le Journal affiche les cinq dernières journées contenant des données et permet de les rouvrir directement.
- L’accueil continue d’afficher uniquement les objectifs en cours dans l’élan du jour.
