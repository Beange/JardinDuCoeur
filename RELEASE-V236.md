# Release V236 — Navigation du Journal

Version applicative : **1.7.9 · build 236**.

## Objectif
Réduire les actions nécessaires pour relire puis modifier une ancienne journée, en particulier sur petit écran, sans toucher au corpus religieux.

## Changements
- Navigation directe vers la journée précédente ou suivante depuis la synthèse du Journal.
- Raccourci contextuel « Revenir à aujourd’hui », désactivé lorsque la journée courante est déjà sélectionnée.
- Le jour suivant reste impossible au-delà d’aujourd’hui.
- Contrôles compacts adaptés aux écrans étroits.
- Le parcours Historique → journée sélectionnée → détail reste conservé en un minimum d’actions.
- Corpus religieux maintenu en standby.
