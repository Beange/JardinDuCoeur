# Release V244 — Interface 1 : Accueil / Aujourd’hui

Version applicative : **1.9.0 · build 244**.

## Objectif
Ouvrir le nouveau cycle d’amélioration interface par interface, en commençant par l’accueil sans modifier la logique métier ni le corpus religieux.

## Changements
- Hiérarchie de l’accueil clarifiée avec un titre « Aujourd’hui » et des repères visuels de section.
- L’intention et l’action principale remontent avant les blocs secondaires pour rendre le point de départ quotidien plus évident.
- Les états du cœur exposent désormais leur sélection via `aria-pressed`.
- Les choix d’état restent confortables sur petit écran grâce à une rangée horizontale compacte.
- Le bloc principal bénéficie d’un contraste et d’une cible d’action renforcés.
- Aucun changement du schéma de données ni du corpus religieux.
