# Release V246 — Interface 3 : Ce que mon cœur porte

Version applicative : **1.9.2 · build 246**.

## Objectif
Améliorer la lisibilité et le confort de l’espace personnel « Ce que mon cœur porte », sans modifier la logique métier ni le corpus religieux.

## Changements
- Introduction courte pour clarifier le rôle de l’écran et réduire la pression de complétion.
- Hiérarchie renforcée entre dhikr, gratitude, du‘â et notes personnelles.
- Libellés visibles associés aux quatre zones de saisie.
- Aides contextuelles courtes sous les titres de section.
- Zone « Entre Allah et moi » volontairement plus ample.
- Confort mobile renforcé pour les zones de texte.
- Corpus religieux inchangé.
