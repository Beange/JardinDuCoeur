# Release V230 — Aujourd’hui contextuel

Version applicative : **1.7.3 · build 230**.

## Objectif

Réduire les actions répétitives sur l’accueil en proposant directement la prochaine étape utile de la journée, à partir des données déjà enregistrées localement.

## Changements

- le bouton principal d’Aujourd’hui devient contextuel ;
- reprise vers Prières & Qur’an, Ce que mon cœur porte, Muhâsabah ou Journal selon l’avancement ;
- ajout d’une indication courte sous le bouton pour expliquer la prochaine étape ;
- la ligne Journal de « Mon élan du jour » utilise la même logique de reprise ;
- aucune donnée religieuse du corpus n’est modifiée ;
- cache PWA incrémenté vers V230.

## Données

Aucune migration de schéma. Le stockage `jardin-du-coeur-v1` et le schéma 1 sont conservés.
